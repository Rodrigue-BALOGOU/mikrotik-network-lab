# MikroTik Network Lab

Practical laboratory dedicated to learning, configuring and testing
MikroTik RouterOS in a network environment.

## Objectives

- Configure network interfaces
- Configure bridges
- Deploy DHCP
- Configure Hotspot and captive portal
- Configure NAT
- Implement firewall rules
- Test and analyze network behavior

## Technologies

- MikroTik RouterOS
- WinBox
- DHCP
- Hotspot
- NAT
- Firewall

## Status

🚧 In progress — laboratory under continuous exploration and improvement.
